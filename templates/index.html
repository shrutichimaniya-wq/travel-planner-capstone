🎓 Capstone Project Overview

Personalized Travel Itinerary Planner

Program: B.Tech Capstone Project for Skill Wallet

Architecture: Python (Flask REST API) + Responsive HTML5/CSS3/Vanilla JS + Google Gemini AI Engine.

Key Engineering Principles:
  • Secure API Key Handling: Gemini API keys are strictly kept on the server inside .env and never exposed to the client.
  • Transparent Demo Fallback: If no API key is provided, the application runs on a curated offline database and clearly labels itself as "Demo Mode".
  • Input Validation: Server-side bounds checking for trip duration (1-14 days), travelers (1-20), and sanitized destination names.
  • Responsible AI: Activity costs and schedules are clearly badged as unverified estimates to prevent user misinformation.
