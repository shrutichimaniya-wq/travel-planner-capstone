🎓 Capstone Project Overview

WanderPlan AI – Personalized AI Travel Itinerary Planner

Capstone Program: Skill Wallet Generative AI with Google Cloud Virtual Internship

Architecture: Python Flask REST backend, Google Gemini API, Open-Meteo Weather API, Leaflet.js OpenStreetMap engine, and Vercel Serverless Hosting.

Core Engineering & Responsible AI Principles:
  • Server-Side Secret Management: GEMINI_API_KEY is kept strictly on the backend and never exposed to the browser.
  • Graceful Demo Fallback: When an API key is missing or quota is exceeded, the application transparently activates its curated offline database with a clear "Demo Mode" label.
  • Live Weather Integration: Connects to Open-Meteo for real-time temperature, humidity, and daily weather outlooks.
  • Geospatial Map Visualization: Plots verified destination landmarks and attractions on OpenStreetMap using Leaflet.
  • Multi-Format Exports: Supports direct PDF downloads via html2pdf.js and print layouts.
